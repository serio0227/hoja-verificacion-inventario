# Hoja de verificación de inventario

## Ejecutar en Windows

1. Instala Python desde https://www.python.org/downloads/ y marca la opción **Add Python to PATH**.
2. Abre la carpeta de esta aplicación.
3. En la barra de dirección del Explorador escribe `cmd` y presiona Enter.
4. Ejecuta: `pip install -r requirements.txt`
5. Ejecuta: `streamlit run app.py`

Se abrirá automáticamente en el navegador. Desde el celular debes abrir la dirección de la aplicación publicada o usar la misma red local.
